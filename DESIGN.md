# Fuzzy Examples Design

## Boundary

This repository is a compact companion set of SQL examples extracted from *Fuzzy Data Matching with SQL*. README.md identifies the source and setup intent; the SQL files are the primary artifact.

## Core decisions

- Keep examples independently readable and ordered by the book’s teaching sequence.
- Preserve setup-oriented DDL and inserts alongside examples so readers can reproduce the demonstrations.
- Favor broadly recognizable SQL where possible, while acknowledging that the original setup was generated with SQL Server tooling.

## Constraints

This is not a general-purpose matching framework or a portability layer for every database engine. Changes should preserve the examples’ pedagogical correspondence to the book.
